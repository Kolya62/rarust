# rarust

**Быстрый распаковщик RAR на Rust без зависимостей**

[![Rust](https://img.shields.io/badge/Rust-orange?logo=rust)](https://www.rust-lang.org)

`rarust` показывает содержимое, проверяет и распаковывает RAR-архивы всех
версий, от RAR 1.4 до RAR 7. Программа написана на Rust и использует только
стандартную библиотеку: никаких внешних крейтов, кода на C и готовых
бинарников.

```text
$ rarust x photos.rar ~/Pictures/

Extracting from photos.rar

Creating    /home/user/Pictures/2024                                 OK
Extracting  /home/user/Pictures/2024/beach.jpg                       100%  OK
Extracting  /home/user/Pictures/2024/sunset.jpg                      100%  OK
All OK
```

## Возможности

| Область | Поддержка |
|---|---|
| **Форматы архивов** | RAR 1.4, RAR 1.5–4.x, RAR 5.0 / 7.0, самораспаковывающиеся архивы (SFX) |
| **Сжатие** | RAR 1.5, 2.x (включая аудио), 3.x (LZ, PPMd, фильтры VM), 5.0/7.0 (фильтры E8, E8E9, ARM, Delta) |
| **Словари** | До 1 ТБ (RAR 7), многопоточная распаковка RAR 5 |
| **Шифрование** | RAR 1.3, 1.5, 2.0, AES-128 (RAR 3.x), AES-256 (RAR 5.0), шифрование заголовков, проверка пароля |
| **Целостность** | CRC32, BLAKE2sp, MAC контрольных сумм для зашифрованных файлов |
| **Многотомные архивы** | Новое (`.partN.rar`) и старое (`.rNN`) именование томов |
| **Восстановление** | Тома восстановления RAR 3.x и 5.0: проверка и воссоздание недостающих томов |
| **Прочее** | Непрерывные (solid) архивы, комментарии, записи быстрого открытия, версии файлов |
| **Ссылки** | Символические и жёсткие ссылки, ссылки на файлы, точки соединения (junction) |
| **Метаданные** | Время изменения, создания и доступа, атрибуты, владельцы в Unix |
| **Windows** | Потоки NTFS, дескрипторы безопасности (ACL), Mark of the Web, сжатие NTFS, кодировки OEM/ANSI |
| **Безопасность** | Защита от выхода за пределы папки и от опасных ссылок, данным архива никогда не доверяем |

Главное:

- **Ноль зависимостей.** Хеши (CRC32, BLAKE2sp, SHA-1, SHA-256), AES, PBKDF2
  и все алгоритмы распаковки реализованы в самом крейте.
- **Проверено.** Протестировано на сотнях архивов, созданных разными
  версиями RAR: листинги, результаты проверки, коды возврата и
  распакованные файлы.
- **Надёжность.** Проверено фаззингом на повреждённых архивах: ни паник, ни
  зависаний.
- **Минимум `unsafe`.** Только системные вызовы в двух небольших модулях,
  `src/win32.rs` и `src/unixsig.rs`. Весь остальной код — безопасный Rust.

## Быстрый старт

```bash
git clone https://github.com/Kolya62/rarust.git
cd rarust
cargo build --release
./target/release/rarust x archive.rar
```

## Использование

```text
rarust <команда> -<ключ 1> -<ключ N> <архив> <файлы...> <путь_для_распаковки/>
```

### Команды

| Команда | Описание |
|---|---|
| `x` | Распаковать с полными путями |
| `e` | Распаковать без путей из архива |
| `t` | Проверить файлы архива |
| `l[t[a],b]` | Показать содержимое (техническое, всё, только имена) |
| `v[t,a,b]` | Подробно показать содержимое |
| `p` | Вывести файл в stdout |

### Примеры

```bash
# Распаковать всё в папку
rarust x archive.rar out/

# Проверить зашифрованный архив
rarust t -pSecret archive.rar

# Распаковать только текстовые файлы, перезаписывая без вопросов
rarust x -o+ archive.rar '*.txt' out/

# Технический листинг: время, хеши, атрибуты
rarust lt archive.rar

# Распаковать многотомный архив (можно начать с любого тома)
rarust x backup.part01.rar

# Вывести файл в stdout
rarust p -inul archive.rar readme.txt | less
```

Часто используемые ключи:

| Ключ | Значение |
|---|---|
| `-p<пароль>` | Задать пароль (`-p` без значения спросит его) |
| `-o+` / `-o-` | Перезаписывать / пропускать существующие файлы |
| `-or` | Автоматически переименовывать файлы |
| `-y` | Отвечать «Да» на все вопросы |
| `-x<маска>` | Исключить файлы |
| `-r` | Обрабатывать подкаталоги |
| `-ola` | Разрешить ссылки с абсолютными путями (только для доверенных архивов) |
| `-ts` | Восстановить время изменения, создания и доступа |
| `-ow` | Восстановить владельцев (Unix) или дескрипторы безопасности (Windows) |
| `-idq` | Тихий режим |

Полный список ключей выводится при запуске `rarust` без параметров.

### Коды возврата

| Код | Значение | Код | Значение |
|---|---|---|---|
| 0 | Успешно | 7 | Неверная командная строка |
| 1 | Некритичное предупреждение | 8 | Недостаточно памяти |
| 2 | Критическая ошибка | 9 | Ошибка создания файла |
| 3 | Ошибка CRC | 10 | Нет файлов для распаковки |
| 4 | Архив заблокирован | 11 | Неверный пароль |
| 5 | Ошибка записи | 12 | Ошибка чтения |
| 6 | Ошибка открытия | 255 | Прервано пользователем (Ctrl+C) |

## Сборка

Нужен Rust 1.87 или новее.

```bash
cargo build --release            # Linux и другие Unix-системы
cargo test --release             # модульные и интеграционные тесты
```

### Windows

Сборка на Windows с MSVC или GNU:

```bash
cargo build --release
```

Кросс-компиляция из Linux с [llvm-mingw](https://github.com/mstorsjo/llvm-mingw):

```bash
rustup target add x86_64-pc-windows-gnullvm
export CARGO_TARGET_X86_64_PC_WINDOWS_GNULLVM_LINKER=/path/to/llvm-mingw/bin/x86_64-w64-mingw32-clang
cargo build --release --target x86_64-pc-windows-gnullvm
```

Библиотека времени выполнения C подключается статически (см.
`.cargo/config.toml`), поэтому `rarust.exe` работает на Windows 10 и новее
без дополнительных DLL.

## Особенности платформ

**Linux / Unix**

- Права доступа, владельцы и группы (`-ow`), символические ссылки.
- Часовой пояс из `/etc/localtime` или переменной `TZ`.
- Ctrl+C удаляет недораспакованный файл и завершает работу с кодом 255.

**Windows**

- Атрибуты файлов и папок, время создания, альтернативные потоки NTFS.
- Точки соединения (junction) и символические ссылки. Для символических
  ссылок нужны права администратора или режим разработчика.
- Дескрипторы безопасности NTFS (`-ow`). Дескрипторы из архива проверяются
  перед передачей системе. Для владельцев и аудита нужны права
  администратора.
- Перенос метки Mark of the Web (`-om[1][=маски]`) и сжатие NTFS (`-oc`).
- Кодировки OEM и ANSI для имён, комментариев и паролей старых архивов.
- Исправление зарезервированных и недопустимых имён (`-oni` — оставить как есть).
- Приоритет процесса и паузы (`-ri`), выключение компьютера после работы (`-ioff`).
- Ключи можно писать и как `-ключ`, и как `/ключ`.

## Структура проекта

```text
src/
├── main.rs, lib.rs      Точка входа командной строки
├── cmddata.rs           Разбор командной строки и ключей
├── archive.rs           Заголовки архивов (RAR 1.4, 1.5–4.x, 5.0)
├── extract.rs, list.rs  Команды распаковки, проверки и листинга
├── unpack/              Распаковщики: v15, v20, v30 (+ RarVM, PPMd), v50, v50mt
├── crypt/               Шифры RAR 1.3–3.x, AES
├── hash/                CRC32, BLAKE2sp, SHA-1, SHA-256, HMAC, PBKDF2
├── recvol.rs            Тома восстановления (Рид-Соломон, 8 и 16 бит)
├── volume.rs            Многотомные архивы
├── extinfo.rs, motw.rs  Ссылки, владельцы, ACL, потоки, Mark of the Web
├── tz.rs, timefn.rs     Часовые пояса (TZif, правила POSIX TZ) и форматы времени
├── win32.rs, winsys.rs  Вызовы Windows API и функции Windows
└── unixsig.rs           Обработка сигналов Unix
```

## Тестирование

```bash
cargo test --release
```

- Модульные тесты: эталонные векторы хешей, AES и PBKDF2, правила часовых
  поясов, проверка дескрипторов безопасности, данные точек повторной
  обработки (reparse point).
- Интеграционные тесты в `tests/` на архивах, созданных RAR 6 и RAR 7:
  методы сжатия, непрерывные и зашифрованные архивы, тома, тома
  восстановления, комментарии, ссылки и имена в Unicode.
